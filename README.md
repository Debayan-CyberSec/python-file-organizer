# Automatic File Organizer (Python)

This project is a Python script that automatically organizes files in a folder
by sorting them into categories such as Images, Videos, Documents, Audio, and Archives
based on file extensions.

## Features
- Detects file types automatically
- Creates folders if they don’t exist
- Moves files into appropriate folders
- Easy to customize

## Technologies Used
- Python
- os module
- shutil module

## Use Case
Useful for automating file management tasks such as organizing Downloads or Desktop folders.
